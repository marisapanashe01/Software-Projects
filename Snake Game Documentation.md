## 🕹️ About the Project

Remember the days of playing Snake on a Nokia phone? The simple graphics, the growing snake, and the challenge of beating your high score?

This project brings that classic gaming experience to the browser using **HTML, CSS, and vanilla JavaScript**.

Guide the snake, navigate the playing field, and enjoy a nostalgic arcade experience while exploring the fundamentals of front-end web development.

## ✨ Highlights

- 🐍 Classic Snake-inspired gameplay
- 🎮 Keyboard-based game controls, if implemented
- 🍎 Food collection and snake growth, if implemented
- 🏆 Score tracking, if implemented
- 🎨 Retro-inspired visual design
- ⚡ Lightweight web technologies
- 🌐 Playable in a browser when deployed

## 🎯 How to Play

1. Open the game in your browser.
2. Start playing using the controls provided by the game.
3. Guide the snake around the playing field.
4. Collect food and grow longer.
5. Avoid collisions and challenge yourself to survive longer.

## 🚀 Getting Started

### Prerequisites

- A modern web browser
- Git
- A code editor such as Visual Studio Code (optional)

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/marisapanashe01/Snake-Game-in-Javascript.git
```

**2. Navigate to the project folder**

```bash
cd Snake-Game-in-Javascript
```

**3. Open the game**

Open the project's `index.html` file in your browser.

You can also use the Live Server extension in Visual Studio Code if your project structure supports it.

## 🌍 Deployment


Once deployed, add your public Vercel URL to this README so visitors can launch the game directly.
